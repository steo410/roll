# TextRoll v0.1

글자의 모양을 피아노 롤 음표로 변환하여 음악을 만드는 웹앱 프로토타입입니다.

## 실행
1. 폴더에서 `index.html`을 더블클릭합니다.
2. Chrome / Edge 사용을 권장합니다.
3. 브라우저의 오디오 정책 때문에 최초 재생은 반드시 `재생` 버튼을 한 번 눌러야 합니다.

## 현재 기능
- 피아노 / 기타 / 베이스 / 드럼 기본 트랙
- 글자 블록 추가
- 글자 블록 드래그 이동
- 8개 핸들로 가로/세로 크기 조절
- 가로 크기 → 연주 시간
- 세로 위치/크기 → 음높이/음역
- 글자 굵기, 음량, 노트 밀도, 옥타브 조절
- Text / Notes / Text+Notes 보기
- Web Audio API로 실제 소리 재생
- BPM / Snap 설정
- 프로젝트 저장 및 불러오기 (`.textroll` JSON)
- 드럼은 글자의 세로 위치에 따라 Kick / Snare / Hat / Clap으로 변환

## 조작법
- 더블클릭: 글자 추가
- 블록 드래그: 이동
- 블록 모서리/변 핸들 드래그: 크기 변경
- Delete: 블록 삭제
- Space: 재생/정지
